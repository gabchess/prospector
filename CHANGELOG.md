# Changelog

## 0.4.0 · 20 September 2026

- Installable Codex and Claude Code marketplaces sharing one self-contained plugin.
- Opportunity review with evidence states, stakeholder roles, alternative explanations and a justified next action.
- Private case template, dated updates and a fictional worked example.
- Plugin-first setup; the existing lead engine remains optional.
- Moved the skill to plugins/prospector. No persona corpus, provider credentials or private cases are bundled.

## 0.3.0 · 20 September 2026

- Configurable countries, industries, company size, contact roles and sources.
- Evidence-aware qualification, suppression and freshness checks.
- Human-reviewed export bound to an exact batch.
- Shared Codex/Claude Code skill, plugin manifests and read-only MCP tool.
- Removed fixed-profile scrapers, persona packaging, duplicated manuals and generated ZIPs. The new version accepts authorized provider output through a common contract.
- Replaced incompatible email-status and approval paths with one tested model. No live provider or outreach claims.
